# Deployment Guide

## Overview

K9 Community is a static Vite application. The production artifact is the `dist/` directory generated by `npm run build`.

## Prerequisites

- Node.js 20+
- npm 10+
- Access to the destination static hosting provider

## Local verification before deploy

```bash
npm install
npm run lint
npm run test
npm run build
python validate.py
```

## Environment model

This repository currently ships a static marketing site and does not require runtime secrets for production.

If forms, analytics, payments, or authentication are added later:

- keep secrets in the platform secret manager
- never commit `.env` files
- expose only `VITE_` variables meant for the browser

## Static deployment workflow

### Option 1: Netlify

Build settings:

- Build command: `npm run build`
- Publish directory: `dist`

### Option 2: Vercel

Framework preset:

- Vite

Build settings:

- Install command: `npm install`
- Build command: `npm run build`
- Output directory: `dist`

### Option 3: GitHub Pages or any CDN-backed static host

```bash
npm install
npm run build
```

Upload the generated `dist/` directory to the target host.

## Post-deploy checklist

- Confirm the homepage loads without console errors
- Confirm anchor navigation scrolls correctly
- Confirm metadata/title render correctly
- Confirm the title-only issue workflow is still present in `.github/workflows`
- Capture a fresh launch screenshot for release notes

## Rollback

Because this is a static site, rollback is straightforward:

1. redeploy the previous known-good `dist/` artifact, or
2. redeploy the previous Git commit that passed validation
